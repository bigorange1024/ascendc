## 1. FIPS 203 Alg.13 语义（k=4, N=256, q=3329）

| 行 | 公式 | 形状 | 本仓实现阶段 |
|----|------|------|--------------|
| **16** | $\hat{\mathbf{s}} \leftarrow \mathrm{NTT}(\mathbf{s})$ | $s$ [4,256] → $\hat{s}$ [4,256] | Phase A：复用 fix-f203 MIX NTT |
| **17** | $\hat{\mathbf{e}} \leftarrow \mathrm{NTT}(\mathbf{e})$ | $e$ [4,256] → $\hat{e}$ [4,256] | 同上（`se` [8,256] 批处理） |
| **18** | $\hat{\mathbf{t}} \leftarrow \hat{A}\circ\hat{\mathbf{s}}+\hat{\mathbf{e}}$ | $\hat{A}$ [16,256]，输出 [4,256] | Phase B：NTT 域 basemul + 累加 + mod q |

**行 18 要点**

- $\circ$ = **MultiplyNTTs**（basemul），**不是** Stage2 的 int8×LUT Cube MatMul。
- 对每个输出行 $p$：$\hat{t}_p = \big(\sum_{j=0}^{3} \mathrm{MultiplyNTTs}(\hat{A}_{p,j},\hat{s}_j) + \hat{e}_p\big) \bmod q$。
- Golden（ONNX / lazy）：内层 **ℤ 上累加**，**一次** mod q；与 tag4 逐步 mod 数值一致。

## 3. 实施路线（分阶段）

### Stage 0（当前）：C 参考 + bin 对拍 — **已完成骨架**

- `hat_inner_product_ref.c`：`MultiplyNTTs` + lazy ∑ + mod q（Barrett / Cast-Div 两档）

- 验收：`bash run_ref.sh` → `max_abs_diff=0`（C host vs Python `ref_inner_product_add`）

### Stage 1：AscendC AIV 行 18（Barrett）

- 向量 basemul（参考 `f203_subop_multiply_ntts` ONNX 拓扑）
- `int64` 累加或分块累加 → `barrett_reduce` / `wrap_mod`（对齐 `stage3_mod_variants.hpp` 变体 0）
- 不经过 Cube MatMul

### Stage 2：mod 变体 Cast+Div

- 末步 mod 切换为 `stage31_mod` 同款 Cast→float Div→int32（变体 2）
- SIM 对比 Barrett 路径性能与数值

### Stage 3：与 fix-f203 串联（可选）

- `mixPass` 扩展：S1+S2+S3 NTT → 写 `ws.sHat/eHat` → AIV 行 18 → `tHat`
- 或 Host 两段 launch：先 `fix-f203` 写 hat，再 `line18` 核
