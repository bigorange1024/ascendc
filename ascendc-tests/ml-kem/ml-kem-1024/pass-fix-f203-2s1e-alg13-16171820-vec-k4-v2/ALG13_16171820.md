# fix-f203-2s1e-alg13-16171820-k4 — Alg.13 行 16–17 NTT + 行 18–20 UB 融合

## 目的

验证 **host 只提供 1×s + 1×e**，设备内复制 s；单趟 MIX 完成 NTT（行 16–17）后，**ŝ/ê/t̂ 全程 UB**，双 AIV **同接口** `Aiv2s1eUbPipeline` 并行完成行 18–20。

| 阶段 | 内容 |
|------|------|
| 行 16–17 | Stage1–3 NTT → ŝ（每核完整 4 poly）+ ê（每核 2 poly） |
| 行 18 | `t̂[p] = mod_q( Σ_j NTT-Mul(â[p,j], ŝ[j]) + ê[p] )` |
| 行 19–20 | UB 内 `ByteEncode₁₂` → **首次算法 GM 写** `ek_polyvec` / `sk_polyvec` |

**约束**：S3 合并 mod 之后到 ByteEncode 结束，**ŝ/ê/t̂ 不得写回 GM**（仅 debug dump / 最终 ek/sk 例外）。

**经验教训（NTT+内积融合）**：[docs/notes/F203-2s1e-NTT内积UB融合技术总结.md](../../docs/notes/F203-2s1e-NTT内积UB融合技术总结.md)（讨论见 [qa/2026-06/…](../../qa/2026-06/2026-06-18-内积布局与NTT内积UB融合讨论.md)）

## 与 alg13 se_pair 的差异

| 项 | alg13 se_pair | 2s1e |
|----|---------------|------|
| ŝ 布局 | 交错行，需 peer `SHAT_PEER` | **每 AIV 握完整 ŝ[0..3]** |
| 行 18 对端 ŝ | GM 握手读 peer | **全在本地 UB**，无 AIV↔AIV |
| 双核接口 | `AivAlg13UbPipeline` | **`Aiv2s1eUbPipeline`**（同结构） |

## Host 输入

```
src [8,256] int32   — poly 0..3 = s，4..7 = e（一份，设备内复制 s）
a_hat [16,256]      — â 矩阵（k=4）
lut_even/odd_stacked — 各 512×128 int8
```

## 设备 Stage1

| AIV | 读 src | 写 S0 |
|-----|--------|-------|
| AIV0 | s[0:4], e[0:2] | ŝ bank + ê 上半 |
| AIV1 | s[0:4] 重复, e[2:4] | ŝ copy bank + ê 下半 |

## Workspace / 平面 mat_c

```
S2: AicMmad(32,256,128)×4 → Aiv2s1ePackMatCPlanar → mat_c_planar [96,128]
S3+: Aiv2s1eUbPipeline（单 TPipe）
```

平面槽位 = dst 槽位：`[s_aiv0×4 | s_aiv1×4 | e_aiv0×2 | e_aiv1×2]`。

## UB 数据布局（每 AIV）

```
ub_ntt[6×256]:
  [0..3]  完整 ŝ
  [4..5]  本核 ê 半片
ub_that[2×256]:
  本核 t̂[p]，p ∈ {0,1} 或 {2,3}
```

行 18：AIV0 算 `p=0,1`；AIV1 算 `p=2,3`；**全部 j 列 ŝ[j] 从本地 ub_ntt 读取**。

## `Aiv2s1eUbPipeline`（双核同接口）

两 AIV 均调用 **同一** `Aiv2s1eUbPipeline::Process(...)`，仅 `subCoreIdx` 不同（`p_begin/p_end`、平面槽位、ek/sk 分片偏移不同）。

```
Process(runS3, runHat, runEncode, loadNttPreset, loadThatPreset)
  ├─ stageS3Into(ub_ntt)     # 平面 mat_c bulk → ŝ/ê（S3 后不再写 GM）
  ├─ hatLine18Into(ub_that)  # â×ŝ+ê → t̂，读 ub_ntt + GM â，写 ub_that
  └─ byteEncode12Pair(...)   # t̂/ŝ → ek/sk 分片，**首次算法 GM 写**
```

**UB 不变量**：`stageS3Into` 完成后，`ub_ntt`/`ub_that` 直至 `byteEncode12Pair` 结束均驻留 UB；中间仅读 GM `a_hat`（常量）与写 debug `dst`/`t_hat` dump（可选）。

| AIV | `p` 范围 | ek/sk 字节偏移 |
|-----|----------|----------------|
| 0 | 0, 1 | `[0, 768)` |
| 1 | 2, 3 | `[768, 1536)` |

## Golden

```python
s_hat, e_hat = NTT(s), NTT(e)   # 从平面 mat_c 推导
t_hat = hat_inner_product_add(a_hat, s_hat, e_hat)
ek/sk = ByteEncode₁₂(t_hat / s_hat)  # C ref
```

## 实现注记

- 平面 mat_c；**Gather 禁令仅适用于三段式 NTT（S1–S3）**，不在此限的步骤（如 ByteEncode）可单独评估 Gather。
- **Stage1 split**（`stage1_config.hpp` / `F203_STAGE1_SPLIT`）：`0` 标量；`1` 整块向量（默认）；`2` 分 tile(32) 向量。`hi=ShiftRight(v,6)`，`lo=Sub(v,Muls(hi,64))`，Cast i32→i16→half→i8。
- `F203_STAGE3_MOD=0`（Barrett）；行 18 final mod `F203_MOD_VARIANT=1`（Barrett 向量，`MOD_Q_I32`）。
- C ref `hat_inner_product_add` golden 固定 `HAT_MOD_SCALAR_I64`；设备 Barrett/Cast 须与标量 golden 一致。
- `Aiv2s1eUbPipeline::Process` = 唯一后 NTT 入口；禁止拆成独立 GM RouteA + Hat + Encode 三趟。
- 行 18 basemul 当前为 `multiply_ntts_half_scalar`；`coef_pairs_vec` 未启用（非全局 Gather 禁令，见指南 §5.1）。
