# 用例自包含与设备全链约束

**适用范围**：`ascendc-tests/` 下全部**活跃**探针与 `examples/incubating/`、`examples/stable/` 下全部算子用例（`frozen/` 只读判决书，不要求 retrofix）。

---

## 1. 自包含

| 允许 | 禁止 |
|------|------|
| 本目录内 `prep/`、`compute/`、`scripts/`、`cmake/`、`thirdparty/`（vendored） | `#include` / Python `sys.path` 指向**其它探针或 example** 源码树 |
| 编译期 `#include` **`library/shared/`**（SHAKE、Keccak、设备 SHA3 等） | 运行时依赖 `ascendc-tests/pass-*`、`examples/incubating/*` 路径 |
| Host golden 引用 **`library/shared/`** 内已登记的 Python/C（如 `merged_kyber_fixed_poly.py`、`fips203_se_sample/`） | 引用仓库根 `thirdparty/ntt_onnx` 等**未 vendored 到本目录**的路径 |
| 仓库 `scripts/sim_env.sh`、`kernel-run-timeout.sh`、`camodel_sim_log.sh`（CANN 壳） | 生产 `run.sh` 依赖 `thirdparty/liboqs`（KAT 脚本除外） |

**规则**：其它包的测试代码会随目录改名而失效；除 `library/shared` 外，需要的能力必须 **vendored 到本用例目录**（抄也得抄过来）。

各 KeyGen 全链用例另见目录内 [`SELF_CONTAINED.md`](../../ascendc-tests/fix-f203-alg13-device-keygen-k4-dual-aiv/SELF_CONTAINED.md) 作实例。

## 2. 设备全链（无 Host 辅助密码计算）

**生产路径**（默认 `bash run.sh`，无 `KEYGEN_VERIFY` / 分段调试 env）：

- Host 只写**合法输入**（如 `seed_d`、**静态** NTT LUT、分段探针的契约 input）
- **禁止**向 `input/` 写入应由设备计算的中间态（KeyGen：`a_hat`/`src`/`rho`/…），除非该用例契约本身就是「给定中间态测 compute 段」（须在 `STATUS.md` 标明**非全链**）
- **禁止** golden fallback（`cp golden_src` 等） silently 替换设备输出
- **禁止** Host 脚本拼接密码学结果冒充设备输出（如 Host `ek‖ρ` 接入全链）

| 允许（Host） | 禁止（生产默认） |
|--------------|------------------|
| Oracle 对拍（`KEYGEN_VERIFY=1`、`verify_result.py`） | Host 算 Â/ŝ/NTT 再 `ReadFile` 进 kernel 当**全链**验收 |
| `KEYGEN_DEBUG_DUMP=1` D2H 调试 | 子进程 `cd` 其它探针 `run.sh` 作默认全链 |
| 缺省时生成**静态 LUT**（与 seed 无关） | liboqs 结果写回 `output/` 代替设备 |

## 3. 审查

```bash
# 跨用例 Python 引用（应无命中，frozen 除外）
rg 'examples/incubating|ascendc-tests/pass-fix|ascendc-tests/fix-' ascendc-tests examples \
  --glob '*.{py,sh,cpp,hpp,cmake}' --glob '!**/frozen/**'

# 仓库根 thirdparty（应仅 thirdparty/ 索引或 KAT；活跃用例 gen_data 应改 thirdparty/ 为本目录）
rg '\.\./.*thirdparty/ntt_onnx' ascendc-tests examples --glob '*.py' --glob '!**/frozen/**'
```
