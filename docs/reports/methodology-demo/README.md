### 节奏

1. **有界推进**：① 已有能力就位（此时不连入目标）；② **按规格一次画出全部缺项与完整路径**，入目标边数从此锁定（黄虚线）；③ 就地补缺（黄→绿）；中途若发现新能力则**先放入再接线**；④ 验收全绿。**入目标边数开局与终局必须一致**，禁止中途拆线、缩成单线或短暂无入边。
2. **无序探索**：开局底座与有界相同（同一批已证能力一次上图）；差异只在后续乱探 / 过补 / 直达落空；步数更多、更晚结束。
3. **连线**：同层不横连；边只表达跨层依赖（向上汇聚），缺口并排但不互串。
4. **图成员**：图上只留能汇入目标的节点；过补债可先只在列表，汇入收口/并入后再上图；终态 `pruneUnreachable` 剪掉仍无路径的孤点。
5. **生长方向**：任一新节点出现时须已有**更低层**入边，且可回溯到 L0；禁止凭空出现再补上层边。L1 输入必须 `L0→L1`（如 `enc→公钥`、`prep0→明文`）。全程须能从目标反推到底座。
6. **无序收口**：过补债不中途下图；收口/并入先接主链末端，再 `attachOne` 逐条并入旁支，禁止最后一步一次性铺边。

### 能力列表语义（两版一致）

1. 新能力先标 **`缺项`**
2. 再把标签改成 **`已证`** 或 **`未采用`**（不删行）
3. 终态列表中 **不得残留「缺项」**

### 视觉

- 绿=已证；黄=缺项/试探（过程中）
- 终态：全绿实线；无序探索图臃肿，有界推进图稀疏
- **无序图 x**：同层用手工非均分坐标（收口/并入也偏心），避免左右镜面对称「假整齐」
