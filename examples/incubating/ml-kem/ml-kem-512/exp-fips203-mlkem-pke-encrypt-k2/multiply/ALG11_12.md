# Alg.11/12 探针说明（B6 k2 multiply）

## 目的

单独验证 **FIPS 203 MultiplyNTTs**（Alg.11）及其内层 **BaseCaseMultiply**（Alg.12）。在 ML-KEM-512 W1/B6 中，它作为 `inner/` 行 18 内积的单对乘模块；算法本身与 k 无关。

## AscendC 结构（仿 `add_custom`）

### 外壳（`multiply_ntts_kernel.cpp`）

```
GM[f,g]
  │ CopyIn: DataCopy → inQueueF/G
  ▼
UB[f,g]
  │ Init（一次）: DataCopy __gm__ ROM → gamma / gatherIdx / interleaveReorder UB
  │ Compute: multiply_ntts_vec_dispatch（见 ALG11_12_VEC_PLAN.md §0）
  ▼
UB[h]
  │ CopyOut: DataCopy
  ▼
GM[h]
```

### 向量 Compute（默认 `ALG11_IMPL=1`，`ALG11_MEM_OPS=1`）

```text
4× Gather(deinterleave) → alg12_elementwise_vec（3× Barrett + Mul）
  → DataCopy(c0,c1 → t1‖t2) → Gather(interleave → h)
```

- `multiply_ntts_kernel.cpp`：**pipe / TQue / DataCopy** 与三阶段循环；Init 灌 ROM。
- `multiply_ntts_ub.hpp`：`ALG11_IMPL=0` C 标量；**默认** `ALG11_IMPL=1` 向量 B2。
- 设计细节与性能结论：[ALG11_12_VEC_PLAN.md](ALG11_12_VEC_PLAN.md) **§0**。

## 算法（FIPS 203）

**Alg.12** — 对 `a = a0 + a1·X`、`b = b0 + b1·X`：

```
c0 ← BarrettReduce(a0·b0 + BarrettReduce(a1·b1)·γ)
c1 ← BarrettReduce(a0·b1 + a1·b0)
```

**Alg.11** — 对 `i = 0 … n/2-1` 调用 Alg.12，**γ[i]=kMlkemGammas[i]**（FIPS Appendix A）。

实现集中在 `alg11_12_ref.h` + `alg11_gammas.h` / `alg11_rom_tables.cpp`（设备 ROM）。

## 输入（固定 varied）

- `f[i] = (17·i + 3) mod q`，`g[i] = (13·i + 7) mod q`（canonical Z_q，非常数）
- golden：`h = MultiplyNTTs(f, g)`，Python 与 C ref 交叉验证

## 与 `inner/` 的关系

| 项 | 说明 |
|----|------|
| `multiply/` | 单次 `MultiplyNTTs(f,g)`，输入输出均为 `[256] int32` |
| `inner/` | 对 `a_hat[2,2,256]` 与 `s_hat[2,256]` 做两行内积，内部复用同一 UB 计算模块 |
| 验收 | 顶层 `run.sh` 顺序跑 `multiply/` 与 `inner/` |
