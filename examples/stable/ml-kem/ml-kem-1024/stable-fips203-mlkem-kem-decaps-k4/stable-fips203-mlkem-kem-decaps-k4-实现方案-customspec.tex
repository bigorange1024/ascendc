在 \textbf{Atlas A2 / Ascend910B4} 上以 AscendC 实现 FIPS 203 \textbf{Algorithm 21}
\texttt{ML-KEM.Decaps()}（参数集 \textbf{ml\_kem\_1024}，$K=4$），经 \textbf{Alg.18}
\texttt{Decaps\_internal} 串联 \textbf{Alg.15} K-PKE.Decrypt 与 \textbf{Alg.14}
K-PKE.Encrypt，并在设备侧完成 $G(m'\Vert h)$、密文比对与 FO 选路后写出共享秘密 $K$。

\textbf{本轮修订（\texttt{\#修改\#}；T19i）}：按 pass-fix / incubating exp
将生产 SIM 自过渡 4 launch \textbf{锁定为 3 launch}（FO 并入 \texttt{l18\_l19} 尾）。
登记表：\dirname{docs/specs/fips203-mlkem1024-kem-decaps-baseline-registry.md}。
预研副本：\dirname{examples/incubating/ml-kem/ml-kem-1024/exp-fips203-mlkem-kem-decaps-k4/}
（T19i 已绿，作镜像来源）。

\textbf{行为对照（只读；禁止把探针当编译依赖）}：
\dirname{ascendc-tests/ml-kem/ml-kem-1024/pass-fix-f203-alg21-kem-decaps-device-k4/}
（\textbf{T19i PASS}：CPU+SIM；$K$ max$=$0；SIM \textbf{3} launch；
D$\,\mathbf{287037}$+E$\,\mathbf{763886}$；单库 + 默认 \texttt{decaps\_1session}；

Phase-D 行为对齐

\section{数学语义（Alg.21 $\to$ Alg.18 $\to$ Alg.15/14）}
\label{sec:math}

\subsection{参数集}

\textbf{ml\_kem\_1024}：$n=256$，$q=3329$，$k=4$；$d_u=11$，$d_v=5$；$\eta=2$。
（与本仓 PKE Decrypt/Encrypt / KEM Encaps 交付同档；勿与 ML-KEM-768 混用。）

\subsection{Algorithm 21（对外）与 Alg.18（设备 I/O）}

对外 API 可对应 Alg.21。\textbf{本用例设备核锁定 Alg.18 形态}
（与 pass-fix 一致）：

\begin{align*}
  \mathrm{dk} &\in \mathbb{B}^{3168},\quad c\in\mathbb{B}^{1568}
    && \text{Host H2D：\texttt{dk\_kem}、$c$} \\
  \mathrm{dk} &= \mathrm{dk}_{\mathrm{PKE}}\Vert\mathrm{ek}\Vert h\Vert z
    && |\mathrm{dk}_{\mathrm{PKE}}|{=}1536,\;|\mathrm{ek}|{=}1568,\;
       |h|{=}|z|{=}32 \\
  m' &\leftarrow \texttt{K-PKE.Decrypt}(\mathrm{dk}_{\mathrm{PKE}},\,c)
    && \text{Alg.15：Phase-D} \\
  (K'\Vert r') &\leftarrow G(m'\Vert h)=\mathrm{SHA3\textrm{-}512}(m'\Vert h)
    && \text{Phase-E prep 前段} \\
  c' &\leftarrow \texttt{K-PKE.Encrypt}(\mathrm{ek},\,m',\,r')
    && \text{Alg.14：随机性输入即为 $r'$} \\
  K &\leftarrow
    \begin{cases}
      K' & \text{若 } c=c' \\
      J(z\Vert c) & \text{否则（SHAKE256，$\ell{=}32$）}
    \end{cases}
    && \text{设备 FO} \\
  &\textbf{输出}\ K\in\mathbb{B}^{32}
\end{align*}

\begin{itemize}
  \item $h$、$z$、$\mathrm{ek}$、$\mathrm{dk}_{\mathrm{PKE}}$：自 \texttt{dk\_kem}
        \textbf{指针偏移}切片；行 1--4 \textbf{不}另开 launch。
  \item $r'$：\textbf{仅} device 写 workspace；prep 以 $r'$ 为种子做 PRF+CBD；
        \textbf{不}落盘为交付物。
  \item $m'$、$c'$、$K'$：workspace；生产路径\textbf{不}D2H。
\end{itemize}

\section{编排与 Launch}
\label{sec:launch}

\subsection{SIM（生产路径；锁定 3 launch）}

\begin{verbatim}
aclInit / CreateStream          # 默认单 session（decaps_1session）
  ├─ Launch-D:  f203_decrypt_device_fused   // MIX；m'_gm
  ├─ Launch-E1: f203_kem_dec_phase_e_prep   // AIV_ONLY, blockDim=2
  │     block0: KemDecPhaseEHead(m',h → K'_gm, r'_gm)  // G
  │     dual AIV: BuildEncryptPrepSinglePipe            // A-hat + CBD <- r'
  ├─ Launch-E2: f203_encrypt_l18_l19        // MIX；pack→c' 后同核 FO→K
  │     dual AIV: tail_pack_shard_gm → SyncAll<isAIVOnly>
  │     AIV0: KemDecFo(c, c', z, K' → K_gm)
  ├─ aclrtSynchronizeStream
  ├─ D2H: K.bin (32)   # 禁止默认 D2H m'/c'/K'
  └─ aclFinalize
\end{verbatim}

\textbf{T19i 要点}：\texttt{l18\_l19} 为 \texttt{MIX\_AIC\_1\_2}；pack 分片后须
\texttt{SyncAll<isAIVOnly=true>()}（双 AIV 写完 $c'$），再由 \texttt{subBlockID==0}
调 \texttt{KemDecFo}。Host 将 $c$/$z$/$K'$/$K$ 指针并入 \texttt{l18\_l19} launch；
\textbf{不再} \texttt{ACLRT\_LAUNCH\_KERNEL(f203\_kem\_dec\_fo\_only)}。

\subsection{CPU（tikicpu 分叉；锁定 6 launch）}

\begin{verbatim}
#1 decrypt_device_fused
#2 f203_kem_dec_phase_e_prep
#3 ntt_y（同 Encrypt CPU）
#4 at_jp
#5 intt_e1
#6 pack_fo（Encrypt pack + 设备 FO；替代纯 pack）
\end{verbatim}

CPU 路径\textbf{不是}与 SIM 同构的完整设备拓扑；验收仍以 $K$ max$=$0 为准。
须用 \texttt{ASCENDC\_BUILD\_CPU}/\texttt{ASCENDC\_BUILD\_SIM} +
\texttt{ASCENDC\_SIM\_HOST\_MODE}，禁止 per-probe 宏分叉破坏单库。

\subsection{SIM 单库与同名头隔离（强制）}

Decrypt 与 Encrypt 树存在同名头时，ascendc precompile \textbf{无法} per-TU 隔离。
本 exp 写码须在 vendor 时完成隔离（推荐：Decrypt 冲突 basename $\to$
\texttt{dec\_*} 并改写 \texttt{\#include}；或等价 shim 生成后纳入本目录且
\textbf{不}依赖仓库外 stable 路径作长期编译根）。
CPU/SIM \textbf{均为单} \texttt{libascendc\_kernels\_*.so}。
默认 \texttt{ASCENDC\_SIM\_HOST\_MODE=decaps\_1session}；
\texttt{decaps\_2session} 仅作对照（非默认）。

\subsection{\texttt{KemDecPhaseEHead}（仅 block0）}

\begin{enumerate}
  \item 自 \texttt{m\_prime\_gm} 读 $m'[32]$ UB。
  \item 自 \texttt{dk\_kem} 偏移读 $h[32]$（或入口已切片指针）。
  \item 拼 $m'\Vert h$（64\,B）$\to$ \texttt{Sha3OneShot}（mdlen$=$64）$\to K'\Vert r'$。
  \item 写 \texttt{K\_prime\_gm}、$r'\to\texttt{r\_prime\_gm}$。
\end{enumerate}

\subsection{\texttt{KemDecFo}（设备 FO；落点锁定）}

\begin{enumerate}
  \item 逐字节（或向量化）比较 $c$ 与 $c'$（长度 1568）。
  \item 相等：$K\leftarrow K'$；否则 $K\leftarrow J(z\Vert c)$
        （\texttt{Shake256OneShot}，输出 32\,B）。
  \item 写 \texttt{K\_gm}。
\end{enumerate}

\textbf{落点}：
\begin{itemize}
  \item \textbf{SIM}：\texttt{f203\_encrypt\_l18\_l19} 内，
        \texttt{tail\_pack\_shard\_gm} 之后；先
        \texttt{SyncAll<isAIVOnly=true>()}，再 \texttt{subBlockID==0} 调用。
  \item \textbf{CPU}：\texttt{f203\_kem\_dec\_pack\_fo} 末尾（pack 后同核）。
\end{itemize}

\textbf{禁止}把「恒选 $K'$」或「Host 比对后写 $K$」当作生产路径；
\textbf{禁止}生产路径再 launch 独立 \texttt{fo\_only}。

\subsection{双 AIV 与头段次序（强制）}

\begin{itemize}
  \item SIM/NPU：\texttt{GetBlockIdx()==0} 先完成 \texttt{KemDecPhaseEHead}，再与
        block1 并行跑 \texttt{BuildEncryptPrepSinglePipe}。
        SampleNTT 只依赖 $\mathrm{ek}$ 尾 $\rho$，\textbf{不}依赖 $r'$；
        CBD/PRF \textbf{仅} block0，故须保证 block0 在 CBD 前已写完
        \texttt{r\_prime\_gm}。
  \item CPU（\texttt{ASCENDC\_CPU\_DEBUG} 且 \texttt{blockDim=2}）：头\textbf{只跑一次}。
  \item Phase-D$\to$Phase-E：同 session 下须保证 $m'$ GM 对后续 launch 可见
        （stream 序 + 必要 sync；对齐 pass-fix \texttt{decaps\_1session}）。
\end{itemize}
