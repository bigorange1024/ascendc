# 双轨实验节奏 — **NPU 优先**（SIM 太慢）

> 更新：2026-09-08 · 用户澄清：**能上机就直接 NPU**；SIM 非门禁、可后补  
> 空闲断连：约 **>4 min**；看门狗 IDLE_MIN≈30  
> 最终权威：NPU 910B3 `ASCEND_DEVICE_ID=0`

## 0. 铁律

1. 主控不停；仅用户明确说「停」才停。排程自定，禁止问「下一刀 / 要不要上板」。  
2. **NPU / SSH / 密钥：只主控**。禁止派 Subagent 上板。  
3. Subagent 本机：**优先 CPU 编通 + gen_data/对拍壳**；**长 SIM 非默认门禁**（除非主控点名要 SIM 证据）。交 FEEDBACK 后主控立刻 rsync 上板。  
4. 主控 ≤3min 必有 SSH/心跳；NPU 用 **远端 nohup 循环** 占卡（本机 SOCKS 掉线不得杀实验）。  
5. **禁止为等 SIM 停 NPU**（X6/X10）。  
6. 新刀：代码可编译 → **主控即可上 NPU**（允许先红再修）。**禁止**用已绿刀无限刷屏占卡当「工作」；sticky 仅在无新树时跑 **1** 个轻用例保活。一件事绿 → **立刻**下一刀上板。  
7. 实例只能用户控制台启动；offline → 本机继续，勿空等。  
8. flock；清脏产物（X8）；禁 `kill -TERM 1`。

## 1. 两轨（优先级）

| 优先级 | 轨 | 谁 | 做什么 |
|--------|-----|-----|--------|
| **P0** | NPU | 主控 | 推码、上板、循环占卡、记 FEEDBACK NPU 栏 |
| P1 | CPU | Subagent | 编通、golden I/O 壳 |
| P2 | SIM | Subagent | 仅主控要求或排错挂死时再跑 |
