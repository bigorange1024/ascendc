# 打字回报格式（禁止回传文件）

> **硬约束**：操作者**无法回传任何文件**；只能在对话里打字发三位编码。  
> 本文件给主控对照用；**不要**要求用户填写后传回本 md。

---

## 推荐打字格式（复制到聊天）

```text
C0: <数字...> | PASS|HANG|TIMEOUT|SKIP [last=NNN expect=MMM] [dev=...]
C1: ...
C2: ...
```

### 最短合法例

```text
C0 PASS
C1 HANG 110
C2 SKIP
```

### 稍完整例

```text
C0: 100 101 110 111 | PASS
C1: 100 101 102 105 110 | HANG last=110 expect=111
C2: SKIP
```
