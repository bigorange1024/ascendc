# TRACE.md — toy-e01-2launch-set4-trace-repeat

对照知识库 §6（三位十进制）。本实验仅打印数字，无长字符串。

| 号 | 谁 | 含义 |
|----|----|------|
| 100 | Host | 将 launch L1 |
| 101 | Host | L1 Sync 返回 |
| 110 | Host | 将 launch L2 |
| 111 | Host | L2 Sync 返回（整轮成功关键点） |
| 400 | L2 AIC | L2 AIC 入口 |
| 401 | L2 AIC | 将 Wait(4) |
| 402 | L2 AIC | Wait(4) 返回（SET 配对成功） |
| 500 | L2 AIV0 | AIV0 入口 |
| 502 | L2 AIV0 | 已 SET(4) |
| 510 | L2 AIV1 | AIV1 入口 |
| 512 | L2 AIV1 | 已 SET(4) |

**判读**：同进程 8 轮应见 **8×** `100/101/110/111`；设备侧每轮 L2 见 `400/401/402` 与 `500/502`、`510/512`（SIM 日志/tee 中）。  
`OMIT_SET4=1`：可见 Host `110` 后无 `111`，设备可有 `400/401` 与 `500/510` 但无 `402`/`502`/`512`，最终 **124**。
