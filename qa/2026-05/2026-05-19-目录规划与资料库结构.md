# 2026-05-19 目录规划与资料库结构

## Context

Clarify separation between external reference material and project-authored docs; standardize folder names in English.

## Decisions

| Path | Purpose |
|------|---------|
| `library/documents/` | Collected open docs, standards, dev materials |
| `library/offline-web/` | Offline web archives |
| `docs/` | Project outputs（后已改为分子目录：research/ specs/ engineering/ 等） |
| `thirdparty/` | Third-party libraries |
| `qa/` | 按日讨论纪要，路径 **`qa/YYYY-MM/YYYY-MM-DD-<关键词>.md`**（见 Rule） |

**README rule:** only root `README.md` in this repo (except upstream trees under `thirdparty/` and clones like `samples/`).
