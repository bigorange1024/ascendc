## 六、ML-KEM-1024 KeyGen 研究与冲刺规划（用户确认）

**背景**：本项目**并非从 0 开始**；NTT、取模、内积等已有前期调研（含 `thirdparty/ntt_onnx` 目标 4 算子语义与交付 bin 经验）。**短期目标**：约 **2 个自然日**内做出 **KeyGen 功能原型**（**不在乎性能**，只在乎功能）。**明日（2026-06-09）再开工**，当日边讨论边具体实现。

### 6.1 参数与算法顺序

| 项 | 约定 |
|----|------|
| **参数集** | **ML-KEM-1024**（**k=4**，n=256，q=3329；Encrypt 阶段 d_u=11，KeyGen 阶段先记 k=4） |
| **阶段 ①** | **PKE.KeyGen**（FIPS 203 **Algorithm 13**）— 生成 K-PKE 密钥 |
| **阶段 ②** | **ML-KEM.KeyGen**（FIPS 203 **Algorithm 16**）— 在 ① 之上 FO 封装、H(ek)、完整 dk |
| **2 天主攻** | **① PKE.KeyGen 功能闭环**；② 时间允许再接 Alg.16（否则记入下一阶段） |

### 6.2 Alg.13 实现分层（AscendC + 嵌入 C）

与 `ntt_study` 目标 4「设备做 16–18、CPU 做哈希/采样/编解码」一致；本仓首版表述如下：

| 区段 | Alg.13 内容 | 首版实现策略 |
|------|-------------|--------------|
| **Host / 胶水** | 行 1–15：随机数、扩展 Â、采样 s/e 等 | **C**（可链入 `main.cpp` 或 `src/`，遵守单 `main`） |
| **SHA3/SHAKE** | G、H 等 | **待考虑**；2 天建议 **Host 调 C**（liboqs 或同源 SHA3），不先声称 AI Core 化 |
| **AI Core 主攻** | 行 **16–17**：NTT(s)、NTT(e) | **AscendC**（函数体内可含 C；已有 NTT/取模调研） |
| **行 18** | t̂ ← Â∘ŝ + ê | **内积 + 加**：**纯 C 嵌入 AscendC 工程**（Host 或核内 C，语义对齐 `F203NttInnerProduct` / `F203PolyVecAddMod`） |
| **编解码** | 行 19+：ByteEncode(ek/dk) | **纯 C 嵌入**（不必 AI Core） |

**验收口径**（Rule）：golden **仅验 I/O**（pk/sk 字节或约定的中间 bin）；不要求与 liboqs/ntt_study **源码同构**。
