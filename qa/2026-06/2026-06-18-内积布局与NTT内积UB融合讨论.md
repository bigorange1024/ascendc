## 1. 内积：`a_hat` 行主序统一

### 1.1 结论

1. **唯一合法 A 布局**（与 alg13 / KeyGen / `hat_inner_product_add` 一致）：

   ```text
   flat(p, j, c) = (p * K + j) * N + c
   input/a_hat.bin  [P_OUT×S_VEC, N]
   input/s_hat.bin  [S_VEC, N]
   ```

2. **废弃 `a_col`**：`(j*P_OUT+p)*N` 仅为早期列合并 `DataCopy` 优化而引入的转置格式，**不是**第二套合法布局；与融合 `stageHatInto` 读法不一致，已全面删除。

3. **实现调整**：去掉 `a_col.bin` / `a_hat_to_a_col`；每 `(p,j)` 按 `a_hat_offset(p,j)` 逐行 `DataCopy`；循环 **外层 j、内层 p**（ŝ[j] 跨 p 复用）。

4. **验收**（Ascend910B4 SIM，`ALG11_VEC_OPTS=1`）：

   | 探针 | CPU | SIM tick | 对拍 |
   |------|-----|----------|------|
   | 全量单 AIV | PASS | **43992** | max_abs_diff=0 |
   | 半行双 AIV | PASS | **26185** | max_abs_diff=0 |

5. **相对旧 `a_col` 全量**：tick ~40805 → ~43932（+~3k，逐行搬入代价）；正确性与 alg13 可插拔性优先。

## 2. 2s1e：NTT + 行18 内积 UB 融合

### 2.1 背景与目标

- 在 **行 16–17 NTT** 与 **行 18 Â·ŝ 全 poly 内积** 之间实现 **单趟 UB 融合**，ŝ 驻留 `ub_ntt`，禁止 S3 后 GM 绕路。
- 性能定标：**单独 NTT SIM ≤15s（理想 ≤10s）**；**NTT+内积 `mixPass=0` tick <100k**。
- 先验 **Â·ŝ dot**，ê / ByteEncode 后接；**依赖 §1 行主序 `a_hat`**。

### 2.2 讨论要点

| 话题 | 结论 |
|------|------|
| 布局 | 同 §1；`flat(p,j,c)=(p*K+j)*N+c` |
| 验证面 | `HAT_LINE18_DOT_ONLY=1` + `golden_t_hat_dot.bin`，通过后再接 ê/encode |
| UB 不变量 | S3→行18 计算路径内 ŝ/t̂ 不离 UB；dump 仅 Process 末尾 |
| 独立探针 | `innerproduct-k4-halfrows` 先 PASS，再融合；**不能代替融合 Init 审查** |
| CPU vs SIM | CPU `mixPass=0` 两段 5→4；**SIM 单趟 mixPass=0** 为融合验收 |
| 尽早探测 | mixPass 分段 + head 对拍；不要等全链路跑完再查 t_hat |
| 文档归档 | 经验教训 → `docs/notes/`；用例目录只留实现方案；讨论 → `qa/`（同日单文档） |

### 2.3 决策过程（关键转折）

1. **融合 SIM 算错、独立 halfrows PASS** → 初判数据/布局，非算力；排除 `a_hat` 读法后仍错。
2. **尝试 S3 后从 GM 读 ŝ**（绕路）→ 仍错 → 确认 **fat TPipe footprint**，非 ub vs gm。
3. **尝试嵌套第二 `TPipe`（HatDotUbKernel）** → dst 全垃圾 → **禁止同 kernel 双 TPipe**。
4. **定位 ROM `pairCount_=64` vs `kRomPairCount=128`** → 修正后 SIM **PASS**，tick **65532**。
5. **否决** 拆 kernel + `dumpNttDebug` + 从 dst 读 ŝ（tick 320k+，违反不变量）。

### 2.4 验收结论

| 项 | 结果 |
|----|------|
| CPU `t_hat` dot | PASS（5→4 两段） |
| SIM `mixPass=0` | PASS，**65532 tick** |
| 红线 <100k | **达标** |
