## 1. 现象收束（已经够窄）

| 观测 | 含义 |
|------|------|
| 已打印 `[kem-enc] launch 2 f203_encrypt_l18_l19 …` / `[kem-dec-e] launch l18_l19 …` | Host 已 `ACLRT_LAUNCH_KERNEL`；卡在随后的 **`aclrtSynchronizeStream`** |
| Encaps 与 Decaps-E **同一句** | 都进同一 MIX 核 `f203_encrypt_l18_l19`（`KERNEL_TYPE_MIX_AIC_1_2`） |
| CPU 连跑 encaps 绿（WSL） | 非 gen_data / 软链 / golden「第二次输入」逻辑死锁 |
| 杀挂死后同 `ASCEND_DEVICE_ID` 连环挂 | **次生污染**（已有 `DeviceGuard`）；**不能**当首次卡死根因 |

**结论一句**：首次主因候选 = **设备侧 MIX CrossCore 死等**（或同核内极早段未推进）；pack / FO **不在** CrossCore 关键路径上（pack 在 INTT+e1/e2 之后；FO 挂在 Decaps 同核尾，若能到 pack 则几乎已过握手）。

## 2. 核内时间线（只认这一条）

源：`examples/stable/ml-kem/ml-kem-1024/stable-fips203-mlkem-kem-encaps-k4/compute/f203_encrypt_l18_l19_kernel.cpp`（PKE Encrypt / Encaps / Decaps-E 同构）。

```text
[AIV0] μ→e₂（前缀）
  │
  ├─ NTT(y):  AIV SET(1) → AIC WAIT(1)+MMAD → SET(3) → AIV WAIT(3)+pack/merge
  │
  ├─ 内积 at_jp（双 AIV；AIV0 可 ByteDecode₁₂(ek)）→ INTT-S1 本地 split
  │
  ├─ GATE:    双 AIV SET(4) → AIC WAIT(4) → SET(8) → 双 AIV WAIT(8)
  │
  ├─ INTT:    AIV SET(1) → AIC WAIT(1)+MMAD → SET(3) → AIV WAIT(3)+pack/merge
  │           （注释强制：INTT 只用 flag 1/3，禁止再用 flag 2）
  │
  └─ e1/e2 加性 →（可选）tail pack / FO → 核结束
```

CrossCore：**channel 模板 `<2, PIPE_MTE2>`**，flag 编号 = `FsmState`（1/2/3/4/8）。  
Host 打印 launch 之后卡死 ⇒ 几乎总是上表某次 **`FsmWait` 永不返回**（或 AIC/AIV 一侧未启动导致对端永等）。

## 3. 假设排序（按可证伪性，不是按「感觉」）

| 秩 | ID | 假设 | 若真：trace 末态典型 | 否证 |
|----|----|------|----------------------|------|
| **1** | **H-pollute** | 卡死主要来自**已污染同卡**（前次 kill 未清驱动会话 / HW flag） | 任意；干净 reset 后不再现 | 干净卡单跑仍卡 → 降为次生 |
| **2** | **H-gate** | **GATE 4↔8** 双 AIV 握手死等（仅一侧 SET4 / AIC 未 SET8 / Wait 错序） | 有 `5`（IP_SIGNAL）无 `6/11/12`；或有 `6,11` 无 `12` | 末行已含 `12` 且继续到 `7/8` |
| **3** | **H-intt** | **INTT 复用 flag 1/3** 与 NTT 残留 / 错用 flag 2 导致死等 | 有 `12` 且有 `7`，长期无 `8` 或无 `9` | 末行含 `9`/`10`/`14` |
| **4** | **H-ntt** | **NTT 段** 首次握手就挂（SET1/WAIT1/SET3） | 空或仅 `0`/`15`，长期无 `1`/`2` | 末行含 `2` 或 `3` |
| **5** | **H-atjp** | 内积/Decode 极慢或异常，**尚未** SET4（表现为「像挂」） | 有 `3` 无 `4`/`5` 且 pop 长期不变 | 数分钟后仍无进展才升为真挂 |
| **6** | **H-ek** | alg19 错密钥「导致」l18 挂 | — | **错数据通常仍能走完握手**（结果错 ≠ CrossCore 死等）。alg19 错与 encaps 挂是**时间序相关**；勿先当因果 |

**刻意排除（本轮不做）**：改 `blockDim`/tiling；换 LUT 形状；改 η；从 frozen 抄同步；并行多路 `-r npu`。

## 4. `F203_L18_TRACE` 槽位速查

Host：`F203_L18_TRACE=1` → `[l18-trace] stages set=… : <已置位下标>`（仅 **AIV0 / AIC** 写槽；AIV1 不写）。

| 槽 | 枚举 | 越过此点意味着 |
|----|------|----------------|
| 15 | `TR_AIV_MU_E2` | 前缀 μ 已写 |
| 0 | `TR_AIV_NTT_SPLIT` | NTT-S1 已 SET(1) |
| 1 | `TR_AIC_NTT_MMAD` | AIC 已做 NTT MMAD |
| 2 | `TR_AIV_NTT_YHAT` | NTT pack/merge 完 |
| 13 | `TR_AIV_DECODE_T` | ek ByteDecode 完（AIV0） |
| 3→4 | at_jp start/done | 内积段推进 |
| 7 | `TR_AIV_INTT_SPLIT` | 本地 INTT-S1（**尚在 SET4 前**） |
| 5 | `TR_AIV_IP_SIGNAL` | AIV0 已 SET(4) |
| 6 | `TR_AIC_IP_WAIT_DONE` | AIC 已过 WAIT(4) |
| 11→12 | GATE AIC/AIV | SET(8)/WAIT(8) 完成 |
| 8 | `TR_AIC_INTT_MMAD` | INTT Stage2 MMAD |
| 9→10→14 | INTT merge / e1 / v | CrossCore **已过**；若仍挂极少见 |

**读法**：看**末行稳定后**最大进度；卡死点 =「已出现的最大关键槽」与「下一预期槽」之间的那次 `FsmWait/Set`。

## 5. 最小实机实验（≤4 刀；带回什么）

**前置（每次）**：

```bash
npu-smi info | sed -n '/Process/,$p'
# 有残留 → 对该 ASCEND_DEVICE_ID reset；确认干净后再跑
export ASCEND_DEVICE_ID=0   # 或另一张确认干净的卡
```

| # | 命令（1024） | 要带回的证据 | 判决 |
|---|--------------|--------------|------|
| **E0** | 干净卡：`cd …/stable-fips203-mlkem-pke-encrypt-k4 && bash run.sh -r npu -v Ascend910B4` | 是否 PASS；耗时 | PASS ⇒ **同 FSM 可完成**；后续 encaps 挂 ⇒ 优先查污染/输入路径，而非「核天生不能跑」 |
| **E1** | 干净卡：`cd …/stable-fips203-mlkem-kem-encaps-k4 && F203_L18_TRACE=1 bash run.sh -r npu -v Ascend910B4` | 全部 `[l18-trace]` 行 + 是否超时；**勿**先跑失败探针 | 对照 §3 表定 H2–H5 |
| **E2** | E1 成功后**同进程/同卡立刻再跑一遍** encaps（可关 TRACE） | 第 2 遍是否挂 | 第 2 挂 ⇒ 会话/flag 残留（H-pollute 变体）；两遍都绿 ⇒ 首次卡更可能是脏卡史 |
| **E3** | （可选）干净卡 alg19：`KEM_KEYGEN_FORCE_REBUILD=1 bash run.sh -r npu …` | `verify` max=；是否 `[FAIL] read lut_*` | **独立线**：错密钥；**不要**用错密钥去解释 CrossCore，除非 E1 卡在 Decode 槽且可复现 |

Decaps 与 Encaps **同核**：E1 已定位 FSM 后，**不必**为「找卡点」再开 Decaps TRACE（phase_e 目前还是裸 `SynchronizeStream`）。Decaps 只在确认 encaps CrossCore 绿之后做正确性回归。

超时杀进程：优先 Ctrl+C 让 `DeviceGuard` 走 Finalize；若 `timeout` 124，先看脚本污染警告，**reset 设备**再下一刀。
