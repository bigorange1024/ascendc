### 实机推荐命令（搬码后）

```bash
cd <repo>
# 0) 搬码后先在仓库根 dry-run，确认分卡（无需 NPU）
NPU_SUITE_DRY_RUN=1 SKIP_L18_RISK=0 NPU_SUITE_PHASE=stable bash scripts/npu_kem_real_machine_suite.sh
NPU_SUITE_DRY_RUN=1 NPU_SUITE_PHASE=examples bash scripts/npu_kem_real_machine_suite.sh
NPU_SUITE_DRY_RUN=1 NPU_SUITE_PHASE=probes_safe bash scripts/npu_kem_real_machine_suite.sh

# 1) 先全部 stable（卡 1）。Encaps/Decaps 须 SKIP_L18_RISK=0
SKIP_L18_RISK=0 NPU_SUITE_PHASE=stable bash scripts/npu_kem_real_machine_suite.sh

# 2) 再 examples / incubating（卡 2）
NPU_SUITE_PHASE=examples bash scripts/npu_kem_real_machine_suite.sh

# 3) 再 ascendc-tests 安全探针（卡 3；不含 alg20/21）
NPU_SUITE_PHASE=probes_safe bash scripts/npu_kem_real_machine_suite.sh

# 4) Decaps 性能：分段 msprof（仍走 stable → 卡 1）
NPU_SUITE_PHASE=msprof_decrypt bash scripts/npu_kem_real_machine_suite.sh   # Phase-D
NPU_SUITE_PHASE=msprof_decaps_e bash scripts/npu_kem_real_machine_suite.sh  # Phase-E（2 launch）

# 5) 全链 device round-trip（定点 SEED_D；suite 默认三件套均 stable → 卡 1）
NPU_SUITE_PHASE=roundtrip bash scripts/npu_kem_real_machine_suite.sh

# 6) l18 诊断（须卡 1 干净 + 显式关闭 SKIP）
SKIP_L18_RISK=0 NPU_SUITE_PHASE=e1 bash scripts/npu_kem_real_machine_suite.sh

# 7) msprof 报告
bash scripts/npu_kem_msprof_report.sh examples/stable/ml-kem/ml-kem-1024/stable-fips203-mlkem-kem-decaps-k4
```

日志：`output/npu_suite/<stamp>/suite.log`；单用例：`output/npu_runs/`。

### PHASE 一览

| PHASE | 内容 | 默认卡 | l18 风险 |
|-------|------|--------|----------|
| `smoke`（默认） | stable Encrypt + KEM KeyGen | 1 | 无 |
| `stable` | 1024 stable 七算子（PKE×3+KEM KeyGen；Encaps/Decaps/ct 受 SKIP） | 1 | Encaps/Decaps 有 |
| `examples` | 1024 incubating（Encaps/Decaps 受 SKIP） | 2 | Encaps/Decaps 有 |
| `e0` | 同 smoke | 1 | 无 |
| `e1` | Encaps + trace | 1 | **有**（默认 SKIP） |
| `e2` | Encaps 连跑两遍 | 1 | **有** |
| `msprof_decrypt` | stable PKE Decrypt msprof（Decaps D 同源） | 1 | 低 |
| `msprof_decaps_e` | `KEM_DECAPS_PHASEE_ONLY=1` msprof | 1 | **有**（E 段 l18） |
| `msprof_decaps` | Decaps 全链 3 launch msprof | 1 | **有** |
| `roundtrip` | `roundtrip_kem_keygen_encaps_decaps.sh -r npu` | 随目录 map | **有** |
| `probes_safe` | alg13/14/15/19 探针（**不含** alg20/21） | 3 | 低 |
| `all` | stable → msprof_decrypt；（E 段/roundtrip/e1 仅 `SKIP_L18_RISK=0`） | 混合 | 混合 |

环境：未设 `ASCEND_DEVICE_ID` 时按 [`npu_device_map.sh`](../../scripts/npu_device_map.sh) 分卡；`NPU_SUITE_FORCE_REBUILD=1`（缺省）、`NPU_GUARD_STRICT=1`。显式 `export ASCEND_DEVICE_ID=N` 覆盖全 suite。

## 4. 卡死 / 污染（脚本行为）

- `kernel-run-timeout` exit **124** 或 suite 任一步失败 → `npu_card_guard_on_failure` 打印 5 步清单（见 08-03/08-05 纪要）
- **禁止**同卡立刻重跑 Encaps/Decaps；须 `npu-smi` 查 Process 或 reset
- 套件默认 **`SKIP_L18_RISK=1`**，跳过 e1/e2/Decaps 全链 msprof
